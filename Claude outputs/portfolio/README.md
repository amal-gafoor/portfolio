# Amal Gafoor — portfolio

Minimal black & white Next.js portfolio with glassmorphism, dark/light toggle and a walking ninja.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Edit content
Everything (name, about, projects, experience, skills, links) lives in `content/site.ts`.
Profile photo: `public/avatar.png`.

## Deploy
Push to GitHub, import the repo in Vercel. No env vars needed.
